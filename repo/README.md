# BolBahi (बोल बही)

A voice-first AI ledger and order assistant for any small shop. Speak in Hindi, English, Marathi, Gujarati, Bengali or Tamil; the app records credit (udhaar), repayments and tomorrow's supplier orders, and prepares WhatsApp + UPI reminders.

## Features
- Language chooser, then login / new account (shop name + password, 8+ characters, confirm password, forgot-password OTP)
- Voice input with confirm-and-undo safety
- Per-shop credit ledger, order list, WhatsApp/UPI links
- Motion wallpaper and sliding-highlight cursor

## Run
Open `index.html` in Chrome. For free hosting, enable GitHub Pages (Settings > Pages > main branch).

## Notes
Data is stored in the browser (localStorage). The OTP is a demo shown on screen; real email/SMS needs a backend. See `BolBahi_Project_Documentation.docx` for full details.
